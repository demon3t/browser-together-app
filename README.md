# Browser Together — приложение для хоста

Браузер, который транслирует свою вкладку (картинку и звук) в активность Discord **Browser Together** (приложение CheremshaBot). Хост пользуется им как обычным браузером, а участники голосового канала смотрят то же самое прямо в Discord.

## Установка

Скачайте [BrowserTogether-Setup.exe](https://92-51-44-211.sslip.io/app/BrowserTogether-Setup.exe) и запустите его.

Windows может показать предупреждение «Система Windows защитила ваш компьютер»: нажмите **«Подробнее» → «Выполнить в любом случае»**. Приложение не подписано платным сертификатом, поэтому Windows его не узнаёт.

## Как начать трансляцию

1. В Discord зайдите в голосовой канал → «Активности» → **CheremshaBot**.
2. Нажмите **«Показывать»**, затем **«Открыть приложение»**.
3. Откроется страница в браузере, а из неё запустится приложение уже с кодом комнаты. Если приложение не запускается, введите код из активности в поле справа вверху и нажмите **Connect**.
4. Открывайте в приложении любые сайты: участники видят их и слышат звук.

Пока в комнате нет зрителей, приложение не кодирует видео и не нагружает компьютер.

## Обновления

При запуске приложение проверяет `latest.yml` на сервере. Если вышла новая версия, работать без обновления нельзя: вместо браузера показывается экран **Update required**. Скачивание начинается только после нажатия **Update**, затем приложение само ставит новую версию и перезапускается. Если автообновление не сработало, там же есть ссылка для ручного скачивания.

## Как это устроено

* `main.js` — окно и вкладка сайта (`WebContentsView`). Регистрирует ссылки `browsertogether://host?code=…` и отдаёт панели захват именно вкладки сайта: `session.setDisplayMediaRequestHandler` возвращает её фрейм для видео и звука.
* `ui/ui.js` — панель: адресная строка и трансляция. Видео сжимается в VP8, звук в Opus (WebCodecs), пакеты уходят по WebSocket на сервер, а сервер раздаёт их зрителям.
* Адрес сервера зашит в приложение (`SERVER_URL` в `main.js`), а не берётся из ссылки. Так чужая ссылка не сможет незаметно отправить вашу трансляцию на посторонний сервер.

Код сервера и активности лежит в отдельном проекте `browser-together`.

## Разработка

```bash
npm install
npm start                         # запуск без установки
npm run dist                      # сборка установщика в dist/
```

Переменные окружения для разработки: `BT_SERVER` (адрес сервера, например `http://localhost:3000`), `BT_START_URL` (стартовая страница), `BT_UPDATE_URL` (откуда проверять обновления) и `BT_BACKGROUND=1` (окно не показывается — для автотестов).

## Выпуск новой версии

1. Поднимите `version` в `package.json`.
2. Выполните `npm run dist`.
3. Загрузите на сервер в `/opt/browser-together/public/app/` три файла из `dist/`: `BrowserTogether-Setup.exe`, `BrowserTogether-Setup.exe.blockmap` и `latest.yml`. Загружайте `latest.yml` **последним**: как только он появится, все приложения потребуют обновиться.
4. Создайте релиз на GitHub: `gh release create v<версия> dist/BrowserTogether-Setup.exe --title "v<версия>"`.

Ссылка «Скачать» в активности и автообновление берут файлы с сервера.
